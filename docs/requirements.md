# Contribly: Requirements

## 1. Problem
Students and freshers often struggle to get started with GitHub open-source contributions. Although there are plenty of open issues available, finding ones that match their skills and interests can be time-consuming.

ContribLy aims to simplify this process by analysing users' GitHub profiles to identify their skills and interests, and recommending relevant open-source issues through skill-based issue matching.

## 2. Target users
A student who has skills but have no open-source contribution due to lower exposure to target issues

## 3. User stories
As a student I had zero knowledge about open-source since these are never tought anywhere. When I came to kknow this it became more hard to find a issue that lies directlly with my skills as there are many. I wanted to escape this hurdle before entering this contribution journey. 

## 4. MVP scope 
A tool where user logs in using their Github account(OAuth). System derives data (skills,tech domains interest) from their existing repo's.Then based on the result it filters out issues and then user can actually use their skill to contribute.

## 5. Later (not in MVP)
Embeddings, Telegram digest, etc.
